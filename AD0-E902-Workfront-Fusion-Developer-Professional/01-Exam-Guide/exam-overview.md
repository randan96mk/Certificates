## Exam Details

| Parameter | Detail |
|---|---|
| **Exam Code** | AD0-E902 |
| **Certification Level** | Professional |
| **Product** | Adobe Workfront Fusion |
| **Delivery** | Online proctored (Meazure Learning / ProctorU) |
| **Proctoring** | Guardian Browser required (webcam + screen share) |
| **Language** | English |
| **Number of Questions** | 33 |
| **Question Format** | Multiple choice, multiple select |
| **Time Limit** | 64 minutes |
| **Passing Score** | 21/33 (63%) |
| **Cost** | $125 USD |
| **Validity** | 2 years (requires renewal) |
| **Prerequisite** | None officially required |

## Who Should Take This Exam?

- Workfront Fusion developers and scenario builders
- Integration specialists working with Workfront ecosystem
- Automation developers connecting Workfront with external systems
- IT professionals implementing workflow automation
- Professionals who design, build, and maintain Fusion scenarios

## Recommended Experience

- **1+ years** working with Workfront Fusion
- Experience with:
  - Building multi-module scenarios with triggers, actions, routers
  - Connecting to REST APIs and webhooks
  - Data transformation using Fusion functions
  - Error handling strategies (Break, Rollback, Ignore, Commit)
  - Data stores and data structures
  - Scheduling and execution management
  - Testing and debugging scenarios

## AD0-E902 (Professional) vs AD0-E907 Fusion Content (Expert)

| Aspect | AD0-E902 (Professional) | AD0-E907 Fusion Section (~8%) |
|---|---|---|
| **Depth** | Deep, Fusion-only exam | Surface-level Fusion knowledge |
| **Questions** | 33 dedicated to Fusion | ~4-5 Fusion questions out of 53 |
| **Scope** | All Fusion capabilities | Basic scenario design + error handling |
| **Functions** | All function categories tested | Common functions only |
| **Error handling** | Deep (all patterns) | Basic awareness |
| **API knowledge** | HTTP module, webhooks, JSON | API concepts only |
| **Best for** | Fusion-focused developers | Workfront generalists |

## Preparation Strategy

### Phase 1: Foundation (Days 1-5)
- Review Fusion fundamentals and module types
- Build 5-10 basic scenarios in sandbox
- Understand trigger types and scheduling

### Phase 2: Deep Dive (Days 6-14)
- Master data structures, functions, and transformations
- Build complex scenarios with routers, iterators, aggregators
- Practice error handling patterns
- Work with HTTP module and webhooks

### Phase 3: Practice (Days 15-21)
- Complete all practice questions
- Build real-world integration scenarios
- Focus on weak areas from practice assessments
