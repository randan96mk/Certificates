## Who Should Take This Exam?

Adobe lists the intended audience as:
- Developer, Automation Engineer
- Automators and process optimization managers
- Integration consultants and system integrators
- Business and applied business analysts
- System administrators across IT/technology domains
- Professionals who design, build, and maintain Fusion scenarios

## Recommended / Minimum Experience

Per the official exam guide, candidates should have:

- **0-12 months** working with Workfront Fusion (Professional-level credential)
- The ability to work with the **Workfront API and API explorer** (but not necessarily proficient in API calls)
- The ability to use modules for the **Workfront app** and other actions including **Create, Read, Update, Delete, and Search**
- The ability to build viable solutions **without hitting Fusion guardrails** (system limits)
- The ability to select appropriate **trigger modules** to accomplish business outcomes
- An understanding of how to use **flow control** (routes, iterators/aggregators, explain flow)
- The ability to conduct **basic troubleshooting and error handling**
- The ability to effectively **test and go live** with a scenario
- The ability to **manage organization teams and users**
- An understanding of the purpose and use of **universal connectors for REST API / OAuth2**

### Additional Hands-on Skills Recommended

Based on community discussions and exam topic analysis, candidates should also have experience with:
- Building multi-module scenarios with triggers, actions, routers
- Connecting to REST APIs and webhooks
- Data transformation using Fusion functions (string, date, math, array)
- Error handling strategies (Break, Rollback, Ignore, Commit, Resume)
- Data stores and data structures
- Scheduling and execution management
- The Fusion Dev Tool for debugging

## Preparation Strategy

### Phase 1: Foundation (Days 1-5)
- Review Fusion fundamentals and module types
- Build 5-10 basic scenarios in sandbox
- Understand trigger types (polling vs instant) and scheduling
- Study function categories: string, date, math, array, general

### Phase 2: Deep Dive (Days 6-14)
- Master data structures, functions, and transformations
- Build complex scenarios with routers, iterators, aggregators
- Practice error handling patterns (all 5 directives)
- Work with HTTP module, webhooks, and JSON parsing
- Study the Fusion Dev Tool for debugging

### Phase 3: Practice (Days 15-21)
- Complete all practice questions
- Build real-world integration scenarios
- Focus on weak areas from practice assessments
- Review scenario design patterns and best practices

## Community Tips and Exam Day Advice

### From Adobe Experience League Community Discussions

**Preparation tips:**
- Practice exams are **much easier** than the actual exam (per community member Jennifer Ma). Use exam prep guides under "Study for exam" tabs -- these better represent where questions come from in documentation
- Adobe provides a **free test instance** for hands-on practice (valid for 3 months); request via form or email wfttstdr@adobe.com
- Focus areas for Fusion developers: **module types, custom API scenarios, JSON structure**
- For the actual exam, the "exam prep guides" are more useful for discovering where the majority of questions come from than the practice exams alone

**Testing environment requirements:**
- Room must have **bare, clean walls and surfaces**
- Only **transparent water bottles** allowed
- **External monitors cannot be used**
- You must be on camera the entire time
- Government-issued ID required (driver's license or passport) -- work badges and bank cards not accepted
- Company VPN may need to be disconnected (network security can prevent test access)
- Guardian secure browser required (no dual monitors, clean desk)
- **Test your system 1-2 days before** the exam

**Discounts and promotions:**
- Adobe runs an annual end-of-year promotion and ad hoc promotions
- Free exams are sometimes available at Adobe Summit for in-person attendees
- Adobe is "exploring" retake discounts for failed attempts
