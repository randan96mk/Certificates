## Overview

Reporting is a core competency for the AD0-E907 exam. You must know standard Report Builder features **and** text mode for advanced customization.

## Key Exam Objectives

- Combine multiple data columns into a single column
- Evaluate the merits of wildcard values in reports and filters
- Report on parent-to-child relationships using native reporting
- Describe how reporting enhances efficient work execution
- Illustrate Workfront Reporting to monitor and improve user adoption
- Determine how a field type would render on a report

## Topics Covered

1. [Report Builder & Text Mode](./report-builder-text-mode.md)
2. [Dashboards & Analytics](./dashboards-analytics.md)
