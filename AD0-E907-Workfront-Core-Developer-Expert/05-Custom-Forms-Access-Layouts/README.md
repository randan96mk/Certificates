## Architect's Design Principles

| Principle | Description |
|---|---|
| **Least Privilege** | Grant minimum access needed for each role |
| **Role-Based Config** | Design around roles, not individual users |
| **Group Delegation** | Empower group admins; don't centralize everything |
| **Form Reusability** | Multi-object forms reduce maintenance |
| **Naming Standards** | Consistent naming for forms, fields, access levels |
