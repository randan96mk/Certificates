## How to Use This Repository

1. **Start with Exam Guides** — Understand the blueprint, domains, and weightings
2. **Study Domain-by-Domain** — Work through each topic folder sequentially
3. **Practice Scenarios** — Test your understanding with scenario-based questions
4. **Integration Patterns** — Review cross-product integration patterns
5. **Revision Checklists** — Use in the final week before each exam
6. **Master Q&A Bank** — Self-test across all domains

## Profile Context

- **Current Role:** AEM Developer, Workfront & Fusion Planning Developer
- **Primary Focus:** Architecture
- **Preparation Focus:** Advanced concepts, real-world patterns, architect-level decision making

- Each file includes a navigation header linking back to section index
- Sources are cited where applicable
